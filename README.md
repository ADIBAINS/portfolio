# Adil Bains · Portfolio

Edit `src/lib/profile.ts` to change résumé entries, skills, social links, and assets.

- `npm ci` installs dependencies.
- `npm run dev` starts Next.js locally.
- `npm run build` exports the website to `dist/`.
- `npm run typecheck` checks TypeScript.

The layout is adapted from [Amrit Rai’s portfolio](https://github.com/retrogtx/amritwt), based on Dillion Verma’s MIT-licensed portfolio template. See [LICENSE](LICENSE).
